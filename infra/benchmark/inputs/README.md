# Inputs du benchmark

Dépose ici **10-15 photos JPG/PNG de vêtements sur cintre, fond neutre** (le parcours réel de l'app : écran 02 PHOTOGRAPHIER).

Conseils pour un benchmark représentatif :

- Varie les types : hauts, robes, vestes, pantalons.
- Varie la difficulté : unis, motifs simples, imprimés complexes, logos/texte (le point faible attendu des modèles).
- Cadre le vêtement en entier, cintre centré, lumière homogène.

Le nom de fichier sert de nom de dossier dans `outputs/` (ex. `veste-verte.jpg` → `outputs/veste-verte/`).

Ces photos ne sont **pas commitées** (gitignore) — seuls ce README et `.gitkeep` le sont.
